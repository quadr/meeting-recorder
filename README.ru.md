MeetRec замечает, что начался звонок, предлагает записать и пишет две отдельные дорожки: ваш микрофон и звук системы. Потом запись можно превратить в текст с разделением, кто говорил.

<p align="center">
  <img src="docs/media/meetrec.gif" width="720" alt="Окно MeetRec: список записанных звонков из Zoom, Teams, Slack и Discord, идущая запись с двумя дорожками, меню записи и экран настроек">
</p>

## Что умеет

- **Замечает звонки.** Zoom, Teams, Slack и Discord узнаются по процессу. Поверх окна звонка появляется плашка с вопросом, записывать или нет.
- **Не теряет первые секунды.** Звук всё время крутится в кольцевом буфере, поэтому запись начинается на несколько секунд раньше, чем вы ответили на вопрос.
- **Два отдельных канала.** Микрофон и звук системы пишутся в один WAV-файл, каждый источник в свой канал.
- **Не мешает.** Значок в строке меню, горячая клавиша, месячные папки, переименование, выбор микрофона.

## Чем отличается

Большинство приложений для записи встреч приводят в звонок бота и держат файлы у себя. MeetRec берёт звук с вашего компьютера и кладёт на ваш диск. В звонке никто не видит лишнего участника, и ни одна запись не уходит с машины, пока вы не попросите расшифровку.

## Установка

Свежая сборка лежит в [релизах](../../releases).

**macOS** — `MeetRec_x.y.z_aarch64.dmg` для Apple Silicon, `MeetRec_x.y.z_x64.dmg` для Intel.

Приложение не подписано сертификатом разработчика Apple, поэтому первый запуск система блокирует. Откройте правым кликом → «Открыть», либо снимите карантин:

```sh
xattr -cr /Applications/MeetRec.app
```

**Windows** — `MeetRec_x.y.z_x64-setup.exe` для установки или `MeetRec_vx.y.z_x64-portable.exe`, если ставить не хочется.

Приложение само замечает новый релиз: раз в сутки спрашивает GitHub и, если вышла версия новее, показывает в окне баннер «Скачать / Позже». «Скачать» открывает страницу релиза в браузере, ставить новую версию — руками, как в первый раз. Ничего, кроме номера версии, при этом не передаётся.

## Что нужно

- **macOS 14.4 или новее.** Звук системы берётся через Core Audio process tap, в более ранних версиях этого механизма нет.
- **Windows 10 или 11.** Там звук системы идёт через WASAPI loopback.

## Разрешения

На macOS система спросит дважды: про микрофон и про запись экрана и звука системы. Нужны оба. Без второго записывается только ваш голос, и звонки перестают определяться сами — приложение узнаёт звонок именно по звуку системы.

Разрешение привязано к конкретному файлу приложения. После обновления macOS может спросить заново.

На Windows отдельных разрешений не требуется.

## Где лежат записи

```
~/Recordings/2026-09/
  2026-09-02_14-30_zoom.wav           канал 1: микрофон; канал 2: звук системы
  2026-09-02_14-30_zoom.transcript/   текст, если попросили
```

На Windows то же самое лежит в `%USERPROFILE%\Recordings\`.

## Расшифровка и приватность

Запись целиком локальная. Расшифровка — нет, и об этом стоит сказать прямо.

Своего сервера расшифровки у MeetRec нет. Вы вписываете в настройки адрес и ключ собственного шлюза, и дорожки уходят туда по HTTPS, по одной. Без настроенного шлюза или явной загрузки в Callabo записи остаются локальными.

Если шлюза нет, можно поднять свой: [selfhost-ai-lab](https://github.com/mmaximov97/selfhost-ai-lab) — он ставится на ваше железо и говорит на том API, которое ждёт MeetRec: `POST /v1/audio/transcriptions/async` для отправки дорожки и `GET /v1/jobs/:id` для опроса. Установка описана там же. Подойдёт любой сервер с этими двумя ручками.

### Загрузка в Callabo

Настройки → Callabo: сохраните Personal Access Token и выберите пространство по умолчанию. Токен хранится в Windows Credential Manager текущего пользователя, а не в конфиге или логах; после сохранения поле очищается. Сохранённый токен не возвращается в JS. Кнопка удаления удаляет только этот токен. На других ОС безопасное сохранение пока не реализовано, замены на открытый текст нет.

В меню готовой записи выберите «Загрузить в Callabo»: откроется диалог с пространством, названием, доступом, командами, языком, метками и дополнительными правами. Название по умолчанию пустое (автоматическое), доступ — `workspace`. Последние успешные команды, язык, метки и права сохраняются отдельно для каждого пространства. Отмена или ошибка их не меняет. Шаблон через API загрузки выбрать нельзя; показаны настройки выбранных команд. Поддерживается единый WAV, старые отдельные дорожки сначала нужно объединить.

Несекретный файл `<запись>.callabo.json` хранит историю ID, пространств, параметров и состояний загрузок. Готовую запись можно загрузить снова, в том числе в другое пространство; список записей показывает названия успешных пространств без повторов. Старые файлы одной загрузки читаются автоматически. Неудачную передачу можно повторить с теми же параметрами в том же пространстве. При неопределённом результате создания/завершения сначала проверьте Callabo; другие пространства не блокируются. Удаление локальной записи не удаляет записи в Callabo.

Повторный запуск показывает существующее окно, в том числе из трея или после сворачивания, не перезапуская запись. При переходе со старой сборки без поддержки одного экземпляра сначала один раз завершите её через меню трея.

Протокол v1 взят из [официального Callabo CLI](https://github.com/rtzr/callabo-cli) v0.1.13: публичный v2 пока не описывает загрузку. Нужен доступ к API/PAT в рабочем пространстве. Протокол проверен на тестовом сервере; совместимость с реальным аккаунтом требует проверки.

### Свой whisper-сервер на этом компьютере

Второй вариант — `whisper-server` из [whisper.cpp](https://github.com/ggml-org/whisper.cpp), запущенный на вашей же машине. Звук не покидает компьютер, ключ не нужен. Чего он не умеет: различать собеседников между собой — в расшифровке будут «Владелец» и «Собеседники», без номеров.

Модели, две, положить в одну папку:

- речь: [`ggml-large-v3-turbo-q5_0.bin`](https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin), 574 МБ — русский почти как у large-v3, в несколько раз быстрее;
- детектор речи: [`ggml-silero-v5.1.2.bin`](https://huggingface.co/ggml-org/whisper-vad/resolve/main/ggml-silero-v5.1.2.bin), 0,9 МБ — без него whisper придумывает текст в паузах, а дорожка микрофона на встрече — это в основном паузы.

**Windows.** Скачать `whisper-bin-x64.zip` из [релизов whisper.cpp](https://github.com/ggml-org/whisper.cpp/releases/latest) и распаковать: архив распаковывается в папку `Release\`; положите обе модели туда же и запустите из неё:

```
.\whisper-server.exe -m ggml-large-v3-turbo-q5_0.bin -l auto --vad -vm ggml-silero-v5.1.2.bin --port 8178 -t 8
```

`-t` — число потоков, ставьте по числу ядер. Без видеокарты часовая встреча считается около часа.

**macOS.** Пакет `brew install whisper-cpp` сервера не содержит, нужна сборка из исходников — три минуты:

```sh
brew install cmake git
git clone https://github.com/ggml-org/whisper.cpp
cd whisper.cpp
cmake -B build && cmake --build build -j
```

Обе модели положите в папку `whisper.cpp`, из неё и запускайте:

```sh
./build/bin/whisper-server -m ggml-large-v3-turbo-q5_0.bin -l auto --vad -vm ggml-silero-v5.1.2.bin --port 8178
```

Metal подхватывается сам: на Apple Silicon часовая встреча считается за несколько минут.

**В приложении.** Настройки → «Расшифровка встреч» → тип сервера «whisper.cpp server», адрес `http://127.0.0.1:8178`. Ключ не нужен.

Одна оговорка: «Отменить расшифровку» в приложении рвёт соединение сразу, но сервер замечает это только между шагами расчёта и прерывает работу не мгновенно — следующая расшифровка может подождать за ней десятки секунд.

## Горячие клавиши

`Ctrl+Shift+R` начинает и останавливает запись. Работает и с закрытым окном.

## Собрать из исходников

Нужны Rust и Node.

```sh
git clone https://github.com/mmaximov97/meeting-recorder
cd meeting-recorder
cargo test --workspace
npm install
npx tauri build
```

Собирать надо через `npx tauri build`, не через `cargo tauri build`.

На каждый push прогоняются тесты и сборка под macOS и Windows. По тегу `vX.Y.Z` собираются и публикуются установщики.

## Как помочь

Issues и pull request'ы приветствуются. Две вещи, которые стоит знать заранее:

- Код и комментарии написаны по-русски, имена функций и переменных тоже. Pull request на любом из двух языков — нормально.
- Работа со звуком покрыта тестами, и они должны оставаться зелёными. Прогоните `cargo test --workspace` перед пушем.
